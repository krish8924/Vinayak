VINAYAK NAGAR MITRA MANDAL - Ganpati Management Website

This is the first working UI prototype.

Included:
- Dashboard: total vargani, total kharch, people count, balance
- Vargani collection form
- Online/Offline payment selection
- QR popup placeholder for online payment
- Success popup with WhatsApp and Copy Phone buttons
- Expense entry page
- Collection and expense records
- Mobile responsive UI

IMPORTANT:
The current prototype stores demo data in browser localStorage.
For the final version, connect the Submit actions to Google Sheets using Google Apps Script.
Replace the "YOUR UPI QR HERE" area with the actual UPI QR image.

Suggested Google Sheet tabs:
1. Collections
2. Expenses
3. Settings
